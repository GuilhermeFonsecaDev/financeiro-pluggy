Tags dos cartões

A tag é o nome exibido nas telas. Cartões com a mesma tag aparecem juntos nos resumos. Deixe a tag vazia para mostrar o cartão individual.

Renomear uma tag em todos os cartões

Ao usar o nome de outra tag existente, os cartões passam a formar um único grupo.
